# PWA (Progressive Web App) - Помощник Сантехника

## 📱 Что такое PWA?

PWA (Progressive Web App) — это веб-приложение, которое можно установить на телефон как обычное приложение. Оно работает офлайн, открывается на весь экран без адресной строки и имеет свою иконку на главном экране.

## ✨ Возможности

- ✅ **Установка на телефон** — работает на Android и iOS
- ✅ **Офлайн работа** — кэширует основные ресурсы
- ✅ **Полноэкранный режим** — без адресной строки браузера
- ✅ **Быстрый доступ** — иконка на главном экране
- ✅ **Автообновление** — service worker автоматически обновляет кэш

## 🚀 Установка приложения

### Android (Chrome, Edge, Samsung Internet)

1. Откройте приложение в браузере
2. Появится всплывающее окно "Установить приложение"
3. Нажмите "Установить"
4. Или: нажмите меню браузера (⋮) → "Установить приложение"

### iOS (Safari)

1. Откройте приложение в Safari
2. Нажмите кнопку "Поделиться" (квадрат со стрелкой)
3. Прокрутите вниз и нажмите "На экран Домой"
4. Нажмите "Добавить"

### Desktop (Chrome, Edge)

1. Откройте приложение в браузере
2. Нажмите иконку установки в адресной строке
3. Или: меню браузера → "Установить приложение"

### Service Worker

Service Worker автоматически:
- Кэширует HTML, CSS, JS файлы
- Кэширует шрифты Google Fonts
- Кэширует изображения и иконки
- Обновляет кэш при изменении файлов
- Работает офлайн

### Кэширование

**Стратегия кэширования:**
- **Cache First** — для шрифтов (кэшируются на 1 год)
- **Stale While Revalidate** — для HTML, CSS, JS
- **Network First** — для API запросов (если есть)

**Что кэшируется:**
- Все `.js`, `.css`, `.html` файлы
- Все `.ico`, `.png`, `.svg` файлы
- Все `.woff2` шрифты
- Google Fonts

## 🔄 Обновления

Приложение автоматически обновляется:
1. Service Worker проверяет новые версии
3. Если есть обновления — скачивает новые файлы
5. Показывает уведомление о обновлении (опционально)
8. Пользователь может перезагрузить страницу

## 🐛 Известные ограничения

### iOS Safari
- Нет автоматического предложения установки
- Нужно вручную добавить на главный экран
- Ограниченная поддержка Service Worker
- Нет push-уведомлений

### Offline режим
- Работают только кэшированные ресурсы
- LocalStorage сохраняется
- Нет доступа к сети

## 🧪 Тестирование PWA

### Chrome DevTools

1. Откройте DevTools (F12)
2. Перейдите на вкладку "Application"
4. Проверьте:
   - Manifest — все иконки загружаются
   - Service Workers — активен
   - Cache Storage — ресурсы кэшируются

### Lighthouse

1. Откройте DevTools (F12)
3. Перейдите на вкладку "Lighthouse"
6. Выберите "Progressive Web App"
8. Запустите аудит
10. Проверьте score: должно быть 100%

## 📱 Проверка установки

### Проверить, установлено ли приложение:

```javascript
// В консоли браузера
window.matchMedia('(display-mode: standalone)').matches
// true — установлено, false — нет
```

### Проверить Service Worker:

```javascript
// В консоли браузера
navigator.serviceWorker.controller
// не null — Service Worker активен
```
