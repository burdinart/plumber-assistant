# Система Push-уведомлений

## 📋 Описание

В приложении "Помощник Сантехника" реализована система push-уведомлений для напоминаний, которая позволяет получать уведомления даже когда приложение закрыто.

## 🎯 Возможности

- ✅ **Системные уведомления** - уведомления отображаются в системном трее телефона
- ✅ **Работа в фоне** - уведомления приходят даже когда приложение закрыто
- ✅ **Быстрые действия** - можно отметить напоминание как выполненное или отложить прямо из уведомления
- ✅ **Автоматическое планирование** - уведомления планируются автоматически при создании напоминания
- ✅ **Перепланирование** - при загрузке приложения все уведомления перепланируются

## 🔧 Как это работает

### 1. Регистрация Service Worker

При загрузке приложения в `main.tsx` регистрируется Service Worker (`/sw.js`), который обрабатывает push-уведомления.

### 2. Запрос разрешения

При первом посещении страницы "Уведомления" (`/notification-settings`) пользователь видит кнопку "Включить уведомления". При нажатии запрашивается разрешение браузера на показ уведомлений.

### 3. Подписка на push-уведомления

После получения разрешения создаётся подписка на push-уведомления через `PushManager`. Подписка сохраняется в `localStorage`.

### 4. Планирование уведомлений

При создании напоминания в хуке `useReminders` автоматически вызывается функция `scheduleLocalNotification`, которая:
- Вычисляет время до напоминания
- Планирует показ уведомления через `setTimeout`
- Сохраняет информацию о запланированном уведомлении

### 5. Показ уведомления

Когда наступает время напоминания, Service Worker показывает системное уведомление с:
- Заголовком "Помощник Сантехника"
- Текстом напоминания
- Иконкой приложения
- Кнопками действий: "Выполнено" и "Отложить на 15 мин"

### 6. Обработка действий

При нажатии на кнопку в уведомлении:
- **Выполнено** - отправляется сообщение в главное окно приложения
- **Отложить** - уведомление откладывается на 15 минут
- **Клик по уведомлению** - открывается приложение на странице напоминаний

### 7. Перепланирование

При каждой загрузке приложения вызывается функция `rescheduleAllNotifications`, которая перепланирует все невыполненные напоминания.

## 🚀 Использование

### Включение уведомлений

1. Откройте приложение
2. Перейдите в меню **"Уведомления"** (или `/notification-settings`)
3. Нажмите **"Включить уведомления"**
4. Разрешите показ уведомлений в браузере
5. Готово! Теперь вы будете получать уведомления

### Создание напоминания с уведомлением

1. Перейдите в раздел **"Напоминания"**
2. Нажмите **"Новое напоминание"**
3. Заполните форму:
   - Текст напоминания
   - Дата и время
   - Приоритет
4. Нажмите **"Создать"**
5. Уведомление будет автоматически запланировано

### Управление уведомлениями

- **Отключить уведомления**: на странице "Уведомления" нажмите "Отключить"
- **Отложить напоминание**: в уведомлении нажмите "Отложить на 15 мин"
- **Отметить выполненным**: в уведомлении нажмите "Выполнено"

## 🔍 Проверка работы

### В консоли браузера (F12)

При загрузке приложения вы увидите:
```
✅ Service Worker зарегистрирован: /plumber-assistant/
```

При создании напоминания:
```
🔔 Запланировано уведомление для напоминания reminder-xxx через xxx мс
```

### В DevTools → Application

1. **Service Workers** - должен быть активен Service Worker
2. **Push Messaging** - должна быть активна подписка
3. **Notifications** - должны быть разрешения

### В системном трее телефона

Когда наступит время напоминания, в системном трее появится уведомление с иконкой приложения.

## 🐛 Решение проблем

### Уведомления не приходят

1. **Проверьте разрешения**:
   - Откройте настройки браузера
   - Перейдите в "Конфиденциальность и безопасность"
   - Найдите настройки уведомлений для сайта
   - Убедитесь, что уведомления разрешены

2. **Проверьте Service Worker**:
   - Откройте DevTools (F12)
   - Перейдите на вкладку Application
   - Проверьте раздел Service Workers
   - Service Worker должен быть активен

3. **Проверьте подписку**:
   - Откройте DevTools Console
   - Выполните: `navigator.serviceWorker.ready.then(reg => reg.pushManager.getSubscription()).then(sub => console.log(sub))`
   - Должна отобразиться информация о подписке

### Уведомления приходят, но не работают действия

1. **Проверьте консоль** на наличие ошибок
2. **Убедитесь**, что приложение открыто хотя бы в одной вкладке
3. **Перезагрузите страницу** и попробуйте снова

### Уведомления не перепланируются после перезагрузки

1. **Проверьте localStorage**:
   - Откройте DevTools → Application → Local Storage
   - Найдите ключ `plumber-assistant-reminders`
   - Убедитесь, что напоминания сохранены

2. **Проверьте консоль** на наличие ошибок при загрузке

## 📊 Технические детали

### Service Worker (public/sw.js)

Обрабатывает события:
- `push` - показывает уведомление при получении push-сообщения
- `notificationclick` - обрабатывает клики по уведомлению
- `message` - обрабатывает сообщения от главного потока

### Хук usePushNotifications

Предоставляет:
- `isSupported` - поддерживаются ли push-уведомления
- `permission` - текущее разрешение (default/granted/denied)
- `subscription` - текущая подписка
- `requestPermission()` - запрос разрешения
- `subscribeToPush()` - подписка на push
- `unsubscribeFromPush()` - отписка от push

### Утилиты планирования

- `scheduleLocalNotification(reminder)` - планирование уведомления
- `cancelScheduledNotification(id)` - отмена уведомления
- `showImmediateNotification(title, options)` - немедленный показ
- `rescheduleAllNotifications()` - перепланирование всех уведомлений

## 🔒 Безопасность и приватность

- ✅ Уведомления работают только после явного разрешения пользователя
- ✅ Все данные хранятся локально в браузере
- ✅ Не используется внешний сервер для push-уведомлений
- ✅ Пользователь может отключить уведомления в любой момент
