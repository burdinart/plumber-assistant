# Помощник Сантехника

Профессиональное веб-приложение для сантехников с калькуляторами, справочниками, CRM и финансовым учётом.

## 🚀 Деплой на GitHub Pages

### Автоматический деплой

Приложение настроено для автоматического деплоя на GitHub Pages через GitHub Actions.

**Шаги для деплоя:**

1. **Настройте GitHub Pages в репозитории:**
   - Перейдите в Settings → Pages
   - В разделе "Build and deployment" выберите "GitHub Actions"

2. **Запушьте изменения в ветку `main`:**
   ```bash
   git add .
   git commit -m "Fix GitHub Pages deployment"
   git push origin main
   ```

3. **Дождитесь завершения деплоя:**
   - Перейдите в вкладку "Actions"
   - Дождитесь завершения workflow "Deploy to GitHub Pages"

4. **Откройте приложение:**
   - URL: `https://burdinart.github.io/plumber-assistant/`

### Проверка после деплоя

После деплоя проверьте:

1. **Главная страница загружается:**
   - Откройте `https://burdinart.github.io/plumber-assistant/`
   - Должна загрузиться главная страница приложения

2. **PWA manifest обнаружен:**
   - Откройте DevTools (F12) → Application → Manifest
   - Должен отобразиться манифест PWA

3. **Service Worker зарегистрирован:**
   - DevTools → Application → Service Workers
   - Должен быть активный service worker

4. **Все ресурсы загружаются без ошибок 404:**
   - DevTools → Console
   - Не должно быть ошибок 404

### Установка как PWA

**На Android:**
1. Откройте приложение в Chrome
2. Нажмите меню (⋮) → "Установить приложение"
4. Или появится автоматическое предложение

**На iOS:**
1. Откройте приложение в Safari
3. Нажмите "Поделиться" → "На экран «Домой»"
6. Нажмите "Добавить"

**На Desktop:**
1. Откройте приложение в Chrome/Edge
3. Нажмите иконку установки в адресной строке
6. Или меню → "Установить приложение"

## 🛠️ Локальная разработка

### Установка зависимостей

```bash
npm install
```

### Запуск dev-сервера

```bash
npm run dev
```

Приложение будет доступно по адресу: `http://localhost:3000/plumber-assistant/`

### Сборка для production

```bash
npm run build
```

Результат сборки будет в папке `dist/`

### Предпросмотр production-сборки

```bash
npm run preview
```

## 🐛 Решение проблем

### Проблема: 404 при обновлении страницы

**Решение:** Убедитесь, что в настройках GitHub Pages выбран "GitHub Actions" как источник деплоя.

### Проблема: Не загружаются ресурсы

**Решение:**
1. Проверьте, что `base` в `vite.config.js` установлен на `/plumber-assistant/`
2. Проверьте, что `basename` в React Router установлен на `/plumber-assistant`
3. Очистите кэш браузера (Ctrl+Shift+R)

### Проблема: PWA не устанавливается

**Решение:**
1. Убедитесь, что сайт работает по HTTPS
2. Проверьте manifest.webmanifest в DevTools
3. Проверьте service worker в DevTools

## 📞 Поддержка

Если возникли проблемы:
1. Проверьте логи деплоя в GitHub Actions
2. Проверьте консоль браузера на ошибки
4. Убедитесь, что все пути начинаются с `/plumber-assistant/`
