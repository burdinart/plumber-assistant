# Система версионирования

## 📋 Описание

В приложении "Помощник Сантехника" реализована система версионирования, которая позволяет:
- Отслеживать текущую версию приложения
- Вести историю изменений (changelog)
- Отображать версию в интерфейсе
- Логировать версию в консоль при запуске
- Проверять обновления при загрузке приложения

## 📁 Структура файлов

```
src/
├── version.ts                          # Файл с версией и changelog
├── shared/
│   ├── ui/
│   │   └── VersionBadge.tsx           # Компонент бейджа версии
│   └── hooks/
│       └── useVersionCheck.ts         # Хук проверки обновлений
├── features/
│   └── app/
│       └── components/
│           └── AboutPage.tsx          # Страница "О приложении"
└── main.tsx                           # Логирование версии в консоль
```

## 🔄 Как обновить версию

### Шаг 1: Откройте файл `src/version.ts`

### Шаг 2: Измените номер версии

```typescript
export const APP_VERSION: AppVersion = {
  version: '1.0.1',  // ← Измените номер версии
  buildDate: '15.09.2026',  // ← Обновите дату
  buildTime: new Date().toLocaleTimeString('ru-RU'),
  phase: 'Фаза 2'  // ← Обновите фазу (если нужно)
};
```

### Шаг 3: Добавьте запись в CHANGELOG

```typescript
export const CHANGELOG: ChangelogEntry[] = [
  {
    version: '1.0.1',  // ← Новая версия
    date: '15.09.2026',
    phase: 'Фаза 2',
    changes: [
      '✅ Добавлена новая функция',
      '🔧 Исправлена ошибка',
      '🎨 Улучшен интерфейс'
    ]
  },
  {
    version: '1.0.0',  // ← Предыдущая версия
    date: '14.09.2026',
    phase: 'Фаза 1',
    changes: [
      '🎉 Первый релиз приложения',
      // ... остальные изменения
    ]
  }
];
```

### Шаг 4: Закоммитьте и запушьте изменения

```bash
git add .
git commit -m "chore: bump version to 1.0.1"
git push origin main
```

## 🎯 Что происходит при обновлении

1. **В консоли браузера** (F12) отображается новая версия
2. **В футере приложения** обновляется бейдж версии
3. **На странице "О приложении"** отображается новая версия и changelog
4. **В localStorage** сохраняется новая версия (для отслеживания обновлений)

## 📊 Формат версионирования

Используется семантическое версионирование (SemVer): `MAJOR.MINOR.PATCH`

- **MAJOR** (1.0.0 → 2.0.0): Значительные изменения, несовместимые с предыдущими версиями
- **MINOR** (1.0.0 → 1.1.0): Добавление новой функциональности без нарушения обратной совместимости
- **PATCH** (1.0.0 → 1.0.1): Исправление ошибок без изменения функциональности

## 🎨 Отображение версии

### В футере приложения
```tsx
<VersionBadge />
```
Отображает: `ℹ️ v1.0.0 • 14.09.2026`

### На странице "О приложении"
- Текущая версия
- Дата и время сборки
- Текущая фаза разработки
- Полная история изменений
- Ссылки на GitHub

### В консоли браузера
```

Версия: 1.0.0

Фаза 1
GitHub: https://github.com/burdinart/plumber-assistant

```

## 🔍 Проверка версии

### В браузере
1. Откройте приложение
2. Нажмите F12 для открытия DevTools
3. Перейдите на вкладку Console
4. Увидите информацию о версии

### В интерфейсе
1. Посмотрите в футер приложения (внизу страницы)
2. Или перейдите в меню "О приложении"

## 📝 Примеры записей в CHANGELOG

### Добавление новой функции
```typescript
{
  version: '1.1.0',
  date: '20.09.2026',
  phase: 'Фаза 2',
  changes: [

    '✅ Добавлен справочник материалов',
    '🎨 Улучшен дизайн главной страницы'
  ]
}
```

### Исправление ошибок
```typescript
{
  version: '1.0.1',
  date: '16.09.2026',
  phase: 'Фаза 1',
  changes: [
    '🔧 Исправлена ошибка расчёта в калькуляторе',
    '🔧 Исправлено сохранение данных в localStorage',

```

### Значительное обновление
```typescript
{

    '⚡ Улучшена производительность',
    '🔒 Повышена безопасность'
  ]
}
```
