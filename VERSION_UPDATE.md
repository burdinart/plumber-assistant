# 🔄 Система обновления версии приложения

## Проблема
При деплое на GitHub Pages версия приложения не обновлялась автоматически из-за агрессивного кэширования Service Worker.

## Решение

### 1. Версионирование в `src/version.ts`
При каждом релизе обновляйте версию:
```typescript
export const APP_VERSION: AppVersion = {
  version: '1.0.2', // ← Обновлять здесь
  buildDate: getCurrentDate(),
  buildTime: getCurrentTime(),
};
```

### 2. Версионирование кэша в `vite.config.js`
Обновите `CACHE_VERSION`:
```javascript
const CACHE_VERSION = 'v1.0.2'; // ← Обновлять здесь
```

Это автоматически изменит:
- Имя кэша прекача: `plumber-assistant-v1-0-2`
- Имя кэша runtime: `plumber-assistant-runtime-v1-0-2`

### 3. Чеклист перед деплоем

```bash
# 1. Обновить версию в src/version.ts
# 2. Обновить CACHE_VERSION в vite.config.js
# 3. Добавить запись в CHANGELOG
# 4. Запустить сборку
npm run build

# 5. Проверить версию в dist/sw.js
grep "plumber-assistant-v" dist/sw.js

# 6. Задеплоить на GitHub
git add .
git commit -m "chore: release v1.0.2"
git push
```

## Как работает обновление

1. **При загрузке страницы**:
   - Browser проверяет наличие нового `sw.js`
   - Если хэш файла изменился → запускается установка нового SW

2. **При активации нового SW**:
   - Старые кэши удаляются (`cleanupOutdatedCaches: true`)
   - Новый кэш создаётся с новым именем (включает версию)

3. **Пользователь получает**:
   - Автоматическую перезагрузку страницы
   - Свежую версию приложения
   - Актуальные данные в консоли

## Логирование

В консоли браузера вы увидите:
```
Помощник Сантехника
Версия: 1.0.2
Сборка: 20.01.2025 14:30:45
[SW] Service Worker registered with scope: /plumber-assistant/
[SW] New service worker available
```

## Примечания

- **Дата и время сборки** обновляются автоматически при каждой загрузке приложения
- **Номер версии** нужно обновлять вручную при каждом релизе
- **Имя кэша** меняется автоматически на основе `CACHE_VERSION`
- **Старые кэши** удаляются автоматически при активации нового SW
