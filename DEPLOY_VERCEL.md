## 🚀 Деплой на Vercel:

### Шаг 1: Подключите репозиторий к Vercel

1. Перейдите на [vercel.com](https://vercel.com)
2. Нажмите "Add New Project"
3. Выберите ваш репозиторий GitHub
4. Vercel автоматически обнаружит настройки

### Шаг 2: Настройте переменные окружения (если нужно)

Vercel автоматически определит:
- Framework Preset: Vite
- Build Command: `npm run build`
- Output Directory: `dist`

### Шаг 3: Деплой

Нажмите "Deploy" и дождитесь завершения.

## ✅ Проверка после деплоя:

После деплоя проверьте:

1. **Главная страница**: `https://your-app.vercel.app/`
2. **Manifest**: `https://your-app.vercel.app/manifest.webmanifest`
3. **Service Worker**: `https://your-app.vercel.app/sw.js`
4. **Иконки**: `https://your-app.vercel.app/icon-192x192.svg`

## 🔍 Проверка PWA:

1. Откройте DevTools (F12)
2. Перейдите на вкладку "Application"
4. Проверьте:
  - **Manifest** - должен быть обнаружен
  - **Service Workers** - должен быть активен
  - **Cache Storage** - должны быть кэшированные файлы

## 📱 Установка PWA:

### Android:
1. Откройте приложение в Chrome
3. Нажмите меню (⋮) → "Установить приложение"
6. Или появится автоматическое предложение

### iOS:
1. Откройте приложение в Safari
3. Нажмите "Поделиться" → "На экран «Домой»"
6. Нажмите "Добавить"

## 🐛 Решение проблем:

### Проблема: 404 при обновлении страницы
**Решение**: Убедитесь, что `vercel.json` содержит rewrites для SPA

### Проблема: Manifest не обнаружен
**Решение**: Проверьте, что manifest.webmanifest доступен по пути `/manifest.webmanifest`

### Проблема: Service Worker не регистрируется
**Решение**: Проверьте консоль на ошибки. Убедитесь, что сайт работает по HTTPS
