# Инструкция по тестированию транзакций

## ✅ Что было исправлено:

1. **Добавлены демо-данные** - 5 транзакций загружаются автоматически при первом запуске
2. **Улучшена валидация** - добавлена проверка на NaN и пустые значения
3. **Добавлено логирование** - все действия записываются в консоль браузера
4. **Увеличено время показа toast** - 2 секунды вместо 1
5. **Улучшена обработка пустых значений** - description и clientId корректно обрабатываются

## 🧪 Как протестировать:

### 1. Откройте консоль браузера (F12)
Перейдите на вкладку "Console" для просмотра логов.

### 2. Перейдите в раздел "Финансы → Транзакции"
Вы должны увидеть 5 демо-транзакций:
- 3 дохода (зелёные)
- 2 расхода (красные)

### 3. Добавьте новую транзакцию
1. Нажмите "Добавить"
2. Выберите тип (Доход/Расход)
3. Введите сумму (например, 5000)
4. Выберите дату
5. Выберите категорию
6. При необходимости выберите клиента
7. Нажмите "Добавить"

### 4. Проверьте консоль
В консоли должны появиться логи:
```
Submitting transaction: {...}
Transaction data: {...}
Adding transaction with data: {...}
New transaction created: {...}
Updated transactions array: [...]
Saving transactions to localStorage: [...]
LocalStorage save result: true
Transaction added: {...}
```

### 5. Проверьте список транзакций
После редиректа вы должны увидеть новую транзакцию в списке.

### 6. Проверьте LocalStorage
Откройте DevTools → Application → LocalStorage → найдите ключ `plumber-assistant-transactions`
Там должен быть массив с вашими транзакциями.

## 🔍 Возможные проблемы и решения:

### Проблема: Транзакция не добавляется
**Решение:**
1. Проверьте консоль на наличие ошибок
2. Убедитесь, что сумма больше 0
3. Убедитесь, что дата выбрана
4. Проверьте, что LocalStorage доступен

### Проблема: Toast не отображается
**Решение:**
1. Проверьте консоль на наличие ошибок
2. Убедитесь, что компонент Toast импортирован правильно
3. Проверьте, что state toast обновляется

### Проблема: Данные не сохраняются в LocalStorage
**Решение:**
1. Проверьте, что LocalStorage доступен
2. Очистите LocalStorage и попробуйте снова
3. Проверьте консоль на наличие ошибок сохранения
