## Технические детали

### Структура EstimateItem:
```typescript
interface EstimateItem {
  id: string;
  name: string;
  unit: string;
  quantity: number;
  price: number;
  type: 'work' | 'material';
}
```

### Параметры URL для автозаполнения:
- `?clientId=xxx` - предвыбор клиента
- `?orderId=xxx` - автозаполнение из заявки
- `?estimateId=xxx` - автозаполнение из сметы (только для ActForm)

### Автоматические расчёты:
- Сумма строки = `quantity * price`
- Итого работ = сумма всех строк с `type: 'work'`
- Итого материалов = сумма всех строк с `type: 'material'`
- Общий итог = Итого работ + Итого материалов
