# Модуль "Финансы" - Помощник Сантехника

## 📋 Описание

Полноценный финансовый модуль для учёта доходов, расходов, создания смет и анализа финансовой деятельности.

## 🎯 Возможности

### 1. Прайс-лист работ
- **15 типовых работ** по категориям:
  - Сантехника (замена смесителя, установка счётчика, замена унитаза и т.д.)
  - Отопление (монтаж радиатора, промывка системы, опрессовка)
  - Канализация (прочистка, установка насоса)
  - Котлы (установка бойлера, монтаж котла, обслуживание)
- Добавление, редактирование и удаление работ
- Поиск и фильтрация по категориям
- Автоматическая загрузка типовых работ при первом запуске

### 2. Сметы
- Создание смет с выбором клиента из базы
- Добавление позиций из прайс-листа или вручную
- Автоматический расчёт итогов
- Применение скидок (процент или фиксированная сумма)
- Статусы смет: Черновик → Отправлена → Принята → Отклонена
- Печать смет в формате PDF (через window.print())
- Срок действия сметы (по умолчанию 14 дней)

### 3. Транзакции
- Учёт доходов и расходов
- Категории для доходов: Частный клиент, Юрлицо, Срочный вызов
- Категории для расходов: Материалы, Транспорт, Инструмент, Реклама, Прочее
- Привязка к клиентам и заявкам
- Фильтрация по типу, категории, периоду
- Баланс за текущий месяц

### 4. Отчёты
- Периоды: день, неделя, месяц, год
- Сравнение с предыдущим периодом
- Топ-5 клиентов по сумме
- Помесячная динамика за год
- Визуализация данных (графики)

### 5. Дашборд финансов
- Баланс за текущий месяц
- Быстрые действия: новая смета, добавить доход/расход
- Активные сметы и неоплаченные заявки
- Последние 5 транзакций

Данные хранятся в LocalStorage под ключами:
- `priceList` - массив работ
- `estimates` - массив смет
- `transactions` - массив транзакций

## 🚀 Использование

### Прайс-лист
1. Перейдите в **Финансы → Прайс-лист**
2. Просмотрите типовые работы или добавьте свои
3. Используйте поиск и фильтры для быстрого поиска

### Создание сметы
1. Перейдите в **Финансы → Сметы**
2. Нажмите "Новая смета"
3. Выберите клиента и заполните адрес
4. Добавьте позиции из прайс-листа или вручную
5. При необходимости примените скидку
6. Сохраните смету

### Печать сметы
1. Откройте смету
2. Нажмите "Печать"
3. В диалоге печати выберите "Сохранить как PDF"

### Учёт транзакций
1. Перейдите в **Финансы → Транзакции**
2. Нажмите "Добавить"
3. Выберите тип (доход/расход)
4. Заполните сумму, дату, категорию
5. При необходимости привяжите к клиенту

### Отчёты
1. Перейдите в **Финансы → Отчёты**
2. Выберите период (день/неделя/месяц/год)
3. Просмотрите статистику и графики
4. Сравните с предыдущим периодом

## 💡 Советы

- Регулярно добавляйте транзакции для точной статистики
- Используйте прайс-лист для быстрого создания смет
- Проверяйте отчёты в конце каждого месяца
- Применяйте скидки для постоянных клиентов
- Печатайте сметы для подписи клиентом

- **React 18** + **TypeScript**

- **React Router v6** для навигации

- **Lucide React** для иконок
- Автоматический расчёт итогов и скидок
- Валидация форм
- Toast-уведомления
- Модальные окна для подтверждений

## 📝 Примечания

- Все данные хранятся локально в браузере
- При очистке браузера данные будут удалены
- Рекомендуется делать резервные копии важных данных
- Печать смет работает через стандартный диалог печати браузера
